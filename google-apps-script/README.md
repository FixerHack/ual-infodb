# Журнал бібліотеки — підключення Google Таблиці

Сайт записує, хто взяв книжку, у Google Таблицю. Посередником є невеликий скрипт
Apps Script усередині цієї таблиці. Налаштування займає приблизно 5 хвилин, і робиться один раз.

## 1. Таблиця і скрипт

1. Створи нову Google Таблицю, наприклад «Бібліотека УАЛ — журнал».
2. У меню відкрий **Розширення → Apps Script**.
3. Видали весь код у файлі `Code.gs` і встав замість нього вміст файлу [`Code.gs`](Code.gs).
4. Збережи (💾). У списку функцій зверху вибери **setup** і натисни **Виконати**.
   Google попросить дозвіл на доступ до таблиці: **Переглянути дозволи → свій акаунт →
   Додатково → Перейти до проєкту → Дозволити**.

Після цього в таблиці з'являться два аркуші:
- **Журнал**: Дата · ID книжки · Назва · Студент · Дія. У колонках «Студент» і «Дія» є спадні списки.
- **Студенти**: список з 38 імен. Його можна змінювати прямо тут, і сайт підхопить зміни сам.

## 2. Публікація

1. У редакторі скрипта натисни **Розгорнути → Нове розгортання**.
2. Тип (⚙️): **Веб-застосунок**.
3. **Виконувати як:** Я. **Хто має доступ:** Усі.
4. Натисни **Розгорнути** і скопіюй **URL веб-застосунку** (він закінчується на `/exec`).

## 3. Підключення до сайту

Встав цю адресу у файл `assets/library.js`:

```js
const LIBRARY_API_URL = "https://script.google.com/macros/s/…/exec";
```

Або просто надішли адресу мені, і я вставлю її сам.

## Як це працює

- Сайт читає журнал і показує, яка книжка вільна, а яка на руках і в кого.
- «Взяти» додає рядок `Взято`, «Повернути» додає рядок `Повернено`.
- Якщо книжку вже хтось узяв, скрипт не дасть узяти її вдруге й скаже, у кого вона.
- Журнал можна правити руками в таблиці. Сайт рахує стан за останнім записом для кожної книжки.
- Якщо зміниш код скрипта, роби **Розгорнути → Керувати розгортаннями → ✏️ → Нова версія**,
  тоді адреса залишиться та сама.
